# Online Donation and Fundraising Management System

## Software Testing Portfolio

### Project Details
- **Subject:** Software Testing
- **Project Title:** Online Donation and Fundraising Management System
- **Department:** Information Science and Engineering
- **College:** M. S. Ramaiah Institute of Technology

### Project Description
The Online Donation and Fundraising Management System is a web-based application that allows individuals and organizations to create fundraising campaigns and receive donations. Donors can browse campaigns, contribute money, and track their donation history. Administrators can manage users, campaigns, and donation records.

### Objectives
- Understand software testing principles and methodologies.
- Identify application modules and functionalities.
- Design test cases using different testing techniques.
- Execute test cases and record actual results.
- Identify and document software defects.
- Perform automated testing using suitable tools.

### Testing Techniques
1. Equivalence Partitioning
2. Boundary Value Analysis
3. Decision Table Testing
4. State Transition Testing
